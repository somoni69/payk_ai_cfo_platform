# Дорожная карта разработки мобильного приложения PAYK (AI CFO Platform)

Этот документ представляет собой единый план разработки мобильного приложения PAYK (iOS / Android) с использованием дизайн-системы **«Ledger»**. Он служит практическим руководством для команды и определяет архитектурные, дизайнерские и функциональные этапы.

---

## 1. Концепция и Философия Дизайна «Ledger»

**Ledger** — это строгая приборная панель для управления деньгами. Дизайн должен транслировать надежность, математическую точность и высокую плотность данных. 

### 🚫 Анти-AI Чек-лист (Чего делать НЕЛЬЗЯ):
* **Никаких фиолетовых и разноцветных градиентов.**
* **Никакого эффекта стекла (glassmorphism).**
* **Никаких иконок-эмодзи в интерфейсе.** Только профессиональный линейный пак иконок (аналог Tabler Icons на вебе — например, `tabler_icons` или `lucide_icons` в Flutter).
* **Не округлять элементы в «пельмени»** (максимальный радиус скруглений задан строго, овалами могут быть только статус-пилюли).
* **Не центрировать контент на каждом экране.** Разметка должна быть выровнена по левому краю, плотная, структурированная в виде аккуратных колонок и таблиц.
* **Никаких мягких размытых теней.** Блоки разделяются тонкими границами. Тень допустима исключительно для перекрывающих всплывающих окон (BottomSheet, Dialogs).

## 2. Спецификация Дизайн-Токенов (Единый Источник Правды)

Все значения описываются в `tokens.json` в корне проекта, из которого генерируется `lib/core/theme/app_theme.dart`. В коде запрещено использовать «сырые» HEX-коды или числовые отступы.

### 🎨 Палитра «Ledger»
| Токен | Цвет | HEX | Семантическое назначение |
| :--- | :--- | :--- | :--- |
| `background` | Фон приложения | `#F7F7F4` | Общий фон экранов |
| `surface` | Фон карточки | `#FFFFFF` | Основной фон контейнеров и блоков |
| `surfaceNested` | Вложенная плашка | `#F1F1EC` | Выделение областей внутри карточек |
| `textPrimary` | Текст основной | `#1A1D29` | Заголовки, основные данные |
| `textSecondary`| Текст вторичный | `#5A6072` | Подписи, второстепенные метки |
| `textTooltip` | Подсказки | `#9AA0AE` | Вспомогательный текст, плейсхолдеры |
| `border` | Границы | `#E6E7EA` | Разделители, рамки полей и карточек |
| `brand` | Индиго (Primary) | `#343B8F` | Активные элементы навигации, primary-кнопки |
| `accentGreen` | Изумруд | `#17795E` | Деньги вверх / Приход / Положительная дельта |
| `accentRed` | Кирпич | `#C0392B` | Деньги вниз / Расход / Отрицательная дельта |
| `accentAmber` | Янтарь (AI/Warning)| `#B7791F` | Все функции AI (прогнозы, рекомендации) и предупреждения |

### Typography (Шрифтовая сетка)
Для обеспечения полной поддержки кириллицы на русском и таджикском языках используется семейство **IBM Plex**:
* **IBM Plex Sans** — для всех текстовых элементов интерфейса (подписи, меню, списки).
* **IBM Plex Mono** — строго для всех денежных сумм, процентов и числовых таблиц (для идеального выравнивания разрядов по вертикали). Должен быть настроен с использованием табличных цифр (Tabular Figures).

#### Шкала размеров (Font Scale)
Использовать только начертания `FontWeight.w400` (Regular) и `FontWeight.w500` (Medium).
* `28px` — Крупные суммы (только Mono, w500)
* `22px` — Заголовки экранов, важные числа (Sans w500 / Mono w500)
* `18px` — Заголовки карточек (Sans w500)
* `15px` — Основной текст (Sans w400/w500, Mono w400)
* `13px` — Вторичный текст / подписи (Sans w400)
* `12px` — Подсказки / статус-пилюли (Sans w500, Mono w400)

### 📐 Формы и Отступы (Layout & Spacing)
* **Сетка отступов**: кратно `4px` (`4`, `8`, `12`, `16`, `24`, `32`, `40`).
* **Радиус скругления карточек**: `10px`.
* **Радиус скругления кнопок и текстовых полей**: `8px`.
* **Радиус статус-пилюль**: `999px` (полное скругление).
* **Границы**: толщина `1px`, цвет `border` (`#E6E7EA`). Без размытия теней.

## 3. Архитектурный паттерн мобильного приложения

Проект строится по принципам Clean Architecture с разделением на фичи (Feature-first).

### Структура каталогов
```
lib/
│
├── core/                         # Системные и общие модули
│   ├── theme/                    # Дизайн-система Ledger
│   │   ├── app_colors.dart       # Цветовые токены
│   │   ├── app_text_styles.dart  # Шрифтовые токены
│   │   └── app_theme.dart        # Сборка ThemeData для Flutter
│   ├── network/                  # HTTP/Dio клиент, обработка ошибок
│   ├── utils/                    # Форматирование валют, дат
│   └── localization/             # Локализация RU / TJ
│
├── features/                     # Функциональные блоки
│   ├── auth/                     # Вход в приложение и биометрия (MOB-05)
│   ├── dashboard/                # Главный экран / Метрики (MOB-01)
│   ├── cash/                     # Касса / Ввод операций (MOB-02, CASH-01, CASH-02)
│   ├── tasks/                    # Задачи и планирование (MOB-03, TASK-01)
│   └── notifications/            # AI Советы и предупреждения (MOB-04, AUD-06)
│
└── main.dart                     # Точка входа в приложение
```

## 5. Правило Рабочего Процесса Команды (Code Review Guideline)

> [!IMPORTANT]
> **Никакого хардкода!**
> Любой Pull Request с прямым указанием цвета (`Color(0xFF...)`) или шрифта вне темы Ledger автоматически отклоняется.
> 
> * **Использование цветов**: `Theme.of(context).extension<LedgerColors>()?.brand` или `Theme.of(context).colorScheme.primary`.
> * **Использование шрифтов**: `Theme.of(context).textTheme.displayLarge` (для Mono сумм) или `Theme.of(context).textTheme.bodyLarge`.
